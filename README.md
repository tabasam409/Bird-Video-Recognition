# 🐦 Bird Species Recognition from Video using YOLOv8

## Description
A real-time bird species recognition system that detects and identifies birds from video footage using the YOLOv8 object detection model by Ultralytics.

## Technologies Used
- Python
- YOLOv8 (Ultralytics)
- OpenCV
- NumPy
- Jupyter Notebook

## How to Run
1. Clone the repository:
   ```
   git clone https://github.com/tabasam409/Bird-Video-Recognition.git
   cd Bird-Video-Recognition
   ```
2. Install dependencies:
   ```
   pip install ultralytics opencv-python numpy jupyter
   ```
3. Open the notebook:
   ```
   jupyter notebook Bird_vedio_recongntion.ipynb
   ```

## Project Structure
- `Bird_vedio_recongntion.ipynb` - Main notebook with YOLOv8 bird detection code
- `Birds.mp4` - Sample bird video for testing
- `yolov8n.pt` - YOLOv8 nano pre-trained model
- `different.png` - Detection result sample
